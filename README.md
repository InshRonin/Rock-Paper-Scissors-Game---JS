# ✊✋✌️ Rock Paper Scissors Game

Welcome to the **Rock Paper Scissors** game! 🎮 This web-based project is a fun implementation of the classic game using **HTML**, **CSS**, and **JavaScript**. Challenge the computer, pick your move, and see who emerges victorious! 🏆




## ✨ Features
- 🎲 **Interactive Gameplay**: Test your luck and strategy!
- 💻 **Responsive Design**: Looks great on all devices.
- 🤖 **Randomized Moves**: The computer's choice keeps you guessing.
- 🔄 **Reset Button**: Start fresh whenever you want.
- 🏅 **Instant Results**: See the winner after each round.




## 🛠️ Technologies Used
- **HTML** 🏗️: Structure and layout.
- **CSS** 🎨: Stylish, user-friendly interface.
- **JavaScript** ⚙️: Game logic and interactivity.





## 🕹️ How to Play
1. 📥 Clone the repository to your local system:
   ```bash
   git clone <repository-link>
   ```
2. 🌐 Open the `index.html` file in your favorite browser.
3. ✊✋✌️ Choose your move: Rock, Paper, or Scissors.
4. 🤖 Watch the computer make its move.
5. 🔄 Use the reset button to start a new game anytime.
6. 🎉 See the result and enjoy the game!






## 🚀 Installation
No installation required! Simply open the `index.html` file in any modern browser, and you're good to go. 🖥️✨
